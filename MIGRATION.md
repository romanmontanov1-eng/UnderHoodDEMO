# UnderHood: публикация публичной части на Render

Исходная версия: коммит 717ae0913cabd6b3687499ce84034131260f914a.
Перед изменениями полная локальная копия репозитория сохранена в underhood-original-717ae091.tar.gz вне каталога публикации.

## Граница переноса

Переносится публичная сборка из 11 страниц. Команда `sh build.sh` создаёт `dist` по явному списку разрешённых файлов. README, этот отчёт, серверные файлы, админка, резервные копии и секреты в публикацию не входят. Публиковать корень репозитория не нужно.

CMS и админка остаются по прежнему адресу:
https://underhood-detailing-montana.romanmontanov1.chatgpt.site/admin

Сайт продолжает читать `/api/content` и фотографии `/api/media/` с этого хоста. Для получения обновлений и фотографий прежний сервер должен оставаться включённым; CORS для публичного API проверен (`Access-Control-Allow-Origin: *`). При ошибке или задержке CMS сайт использует локальные исходные тексты и локальную фотографию студии. CMS не подключает панель платформы к новому сайту: переносится только JSON и изображения.

## Состояние контента на 26 октября 2026

Публичный API прежнего CMS и API действующей версии AppDeploy вернули `{"content":null}`. `content-default.json` действующего сайта полностью совпадает с файлом в этом репозитории; дополнительных работ в нём нет. Реальные работы, цены и отзывы не добавлялись. Три изображения хранятся локально в `assets`; логотип имеет прозрачный альфа-канал.

В браузере админки подтверждены интерфейс и клиентская логика: максимум 50 работ, загрузка фото, преобразование в WebP, уменьшение длинной стороны до 1920 px, водяной знак UNDERHOOD, резервные копии, сохранение и восстановление с ревизией. Неавторизованный GET `/api/admin` возвращает 403. Серверные исходники и авторизованная сессия отсутствуют в репозитории: вход, запись, серверная проверка лимита, восстановление и конфликт ревизий не проверены полностью. Админка и её данные при этой миграции не изменяются.

## Изменения

- Локальный контент применяется сразу; недоступность, невалидный JSON или тайм-аут CMS не мешают ему отображаться.
- Неполные данные CMS дополняются исходными значениями, услуги сопоставляются по ID, галерея ограничена 50 карточками.
- Относительные пути изображений разрешаются от прежнего CMS, допустимы только HTTP(S) URL.
- Длинные тексты помещаются в мобильные блоки; добавлены favicon из исходного логотипа и атрибуты доступности меню.
- После Escape меню возвращает фокус и корректное название кнопки.
- Отдельная сборка `dist` исключает публикацию непубличных файлов.

В подключаемом публичном коде нет SDK, панели AppDeploy и упоминаний платформ в видимых текстах. Упоминание `chatgpt.site` в `content.js` необходимо для действующего CMS; его удаление без переноса CMS отключит обновление контента.
