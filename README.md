# GT Detailing

Сайт детейлинга и автоателье, страницы услуг, галерея, контакты и редактор контента.

## Render

- Build: `npm run build`
- Start: `node render/server.mjs`
- Health check: `/healthz`
- Node.js 22 или новее.
- `CMS_ORIGIN=https://gt-detailing.romanmontanov1.chatgpt.site`

Публичный сервер Render показывает актуальные страницы и фотографии действующего CMS. При недоступности CMS используются последняя полученная страница или исходная сборка. Новые загруженные фотографии при отключённом CMS недоступны. Локальная сборка содержит исходные фотографии, тексты и маршруты, не приватные изменения владельца.

`/admin` и `/admin.html` перенаправляют в защищённую админку действующего CMS. Вход через аккаунт владельца ChatGPT. Запись контента, файлы и резервные копии остаются в постоянном хранилище CMS, а не на временном диске Render. Поддельные заголовки авторизации клиента не передаются в CMS. Публичные запросы не получают доступ к приватному API.

**Не отключать действующий CMS.** Это перенос публичного сайта на Render; отдельная CMS с паролями и собственным постоянным диском в эту публикацию не входит. Такой же принцип использован в опубликованной публичной части UnderHood.

На бесплатном Render Web Service возможен холодный запуск после простоя. Для собственного домена необходимо добавить домен в Dashboard и настроить DNS у регистратора.

## Проверка

`npm run build && npm run check && npm run validate`
