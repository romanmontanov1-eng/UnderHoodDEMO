# UNDERHOOD — HTML / CSS / JavaScript

## Публикация на GitHub Pages
1. Создайте репозиторий, например underhood.
2. Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория: index.html, остальные HTML, style.css, app.js, content.js, content-default.json и папку assets.
3. Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите main и /(root), нажмите Save.
5. Откройте ссылку, которую покажет GitHub Pages после успешной публикации.

Не загружайте сам ZIP вместо файлов. Сохраните вложенную папку assets.

## Состав
11 страниц. style.css — оформление; app.js — меню и анимации; content.js — загрузка контента; assets — изображения.

## Админка и контент
Это публичная часть сайта. GitHub Pages не запускает серверную админку.
Текущие тексты и работы загружаются из существующего публичного CMS API на прежнем сервере chatgpt.site. Вход, редактирование и хранение фотографий остаются там. API-адрес есть в content.js, но на страницах посетителям он не показывается.
Не отключайте прежний сервер до отдельного переноса CMS. При недоступности API HTML содержит исходные тексты и демонстрационные материалы.

В этой сборке нет SDK AppDeploy, платформенной панели и кнопок ChatGPT. Внешние шрифты загружаются из Google Fonts.

## Локальный просмотр
В папке выполните python -m http.server 8000 и откройте http://localhost:8000. Открытие HTML двойным щелчком ограничивает загрузку JSON браузером.
